# mae borowski rigged (import locally)

the possum springs town character is a fan-made model and is **not included** in this repository.

- creator: asterisk ([sketchfab profile](https://sketchfab.com/dylee063))
- source: [mae borowski rigged](https://sketchfab.com/3d-models/mae-borowski-rigged-21b0649aba644fa8ba5b637f0c6731fd)
- license: [cc by-nc-sa 4.0](https://creativecommons.org/licenses/by-nc-sa/4.0/)

to use it, download the model yourself under its license and save it as `project/Assets/StreamingAssets/Characters/Mae/mae_borowski_rigged.glb`. that path is git-ignored. without it, the scene logs a missing-file message and runs without the town character.
