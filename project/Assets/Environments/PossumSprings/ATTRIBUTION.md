# possum springs environment (import locally)

the possum springs scene uses a fan-made recreation of the town from *night in the woods*. the model is **not included** in this repository.

- asset: possum springs, by powerbyte7
- source: https://sketchfab.com/3d-models/possum-springs-bd755222c78a443398e521fc7b7fd9ea
- license: cc attribution-noncommercial-sharealike 4.0

to use the scene, download the asset yourself under its license and place the files at:

- `Models/NITWworld.fbx`
- `Textures/Atlas.png` and `Textures/Leaves.png`

then run the possum springs scene builder from the unity editor menu. these paths are git-ignored so the asset is never committed.
